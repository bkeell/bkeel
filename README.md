# Bkeel Medical Planet (كوكب بكيّل الطبي)

A comprehensive, bilingual (English & Arabic) healthcare and clinical management web application built for **Bkeel Medical Planet**.

## Features

- **Clinical Specialties**: Internal Medicine, Cardiology, Pediatrics, Dermatology, Orthopedics, Dental Care, Diagnostic Laboratory, and 24/7 Urgent Care.
- **Consultant Physician Directory**: Searchable directory of board-certified specialists with credentials, consultation fees, and real-time availability.
- **Appointment Scheduling**: Interactive booking workflow with instant booking reference generation, in-person and telehealth options.
- **Patient Health Portal**: Real-time record of scheduled appointments, continuous vital signs tracking, active electronic prescriptions with refill requests, and diagnostic lab reports.
- **Clinical Symptom Triage**: Interactive smart symptom checker with urgency-level categorization and departmental recommendations.
- **Diagnostic Laboratory Packages**: Catalog of certified diagnostic blood and metabolic panels with home blood draw and clinic options.
- **Bilingual Experience**: Full English and Arabic support with dynamic RTL/LTR layout transitions.
